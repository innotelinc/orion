Orion — A NAS desktop for one Incus container, wired to the machine it runs on.

A NAS desktop for a single Incus container: the files on its data volume, its filesystems, the host's devices and the systemd units that serve it, read and written through a small API rather than invented in the browser. Files, recoverable Trash, spaces, SMB shares, installable apps and the roles that administer them are the machine's own.

View on GitHub Quick start 
npm install

NAS interfaces invent a filesystem.

Every file action is a real call on /srv/storage, and every service is a real systemd unit.

App stores claim an app is installed.

dpkg decides whether it is present and systemd decides whether it answers.

Sharing means a second account system.

SMB accounts are the spaces; Orion never stores the password.
